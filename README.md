# Banking

A next-generation banking experience for South Africa, pitched to Standard Bank as a partnership to elevate its app.

- [**Pitch to Standard Bank**](docs/pitch-standard-bank.md)
- [Product vision & differentiation](docs/product.md)
- [System architecture](docs/architecture.md)
- [Regulatory & compliance path](docs/compliance.md)

**Stack:** React Native (Expo) mobile app, Node.js/TypeScript services, PostgreSQL, Kafka/queue-based events.

> Note: `architecture.md`, `compliance.md` and `roadmap.md` were written for a standalone bank. In the Standard Bank partnership model the bank supplies the licence, core ledger and rails; see the pitch doc for what changes.
