# Product vision

Revolut's moat is breadth (one app for money, FX, cards, investing, business), fast iteration, and low unit cost. Competing head-on on features is a losing game early. Win a wedge first, then expand.

## Pick a wedge (decide before building)
Candidates, in rough order of defensibility:
1. **Underserved segment**: freelancers/creators, migrants sending money home, Africa/emerging-market users, teens/families.
2. **Better core experience**: radically transparent fees, instant everything, real-time spending intelligence.
3. **AI-native money management**: an assistant that categorizes, forecasts cash flow, detects bills/subscriptions, and automates savings, with actions the user confirms.

## Core feature set (parity with Revolut's essentials)
| Area | MVP | Later |
|---|---|---|
| Accounts | Current account, IBAN/account number | Multi-currency wallets, joint accounts, sub-accounts ("pots") |
| Payments | Bank transfers, P2P by handle/phone, request money | Scheduled/recurring, bulk, open-banking pay-by-bank |
| Cards | Virtual debit card, freeze/unfreeze, limits | Physical, disposable virtual cards, Apple/Google Pay |
| FX | Currency exchange at mid-market + small transparent fee | International transfers, FX limit orders |
| Insights | Categorised feed, budgets | Cash-flow forecasting, AI assistant |
| Savings | Pots, round-ups | Interest-bearing vaults, goals |
| Security | Biometrics, device binding, instant card lock, push-approve | Behavioural fraud scoring, scam warnings |
| Later bets | | Stocks/ETFs, crypto, credit, business accounts, subscriptions tiers |

## Principles
- Real-time by default (balances, notifications, settlement where rails allow).
- Every fee shown before the user commits.
- Security and trust are the product; never trade them for velocity.
